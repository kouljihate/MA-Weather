# 🇲🇦 Morocco Weather History App

Historical weather data dashboard for Moroccan regions (1940-2026) using Streamlit and Open-Meteo ERA5 API.

## Features
- 50+ years of historical weather data
- 27 Moroccan regions
- Interactive temperature and precipitation charts
- CSV export functionality

## Data Source
Open-Meteo Historical Weather API (ERA5 reanalysis) - CC BY 4.0

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Automatically deployed on Streamlit Cloud from this repository.
